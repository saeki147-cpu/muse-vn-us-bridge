# Ảnh tham chiếu — thư mục refs/

5 ảnh khóa của diễn viên v19 nằm ở đây, dạng `.b64` (base64 của file
ảnh gốc). Ảnh nhị phân không đẩy trực tiếp lên GitHub qua connector
được, nên repo lưu bản base64; bot trên máy Mỹ tự tải về và giải mã
thành file ảnh.

| File | Ảnh gì |
|---|---|
| `v19-vay-trang.jpg.b64` | Ảnh chính: váy trắng hai dây ngắn, vòng 1 đúng 106cm (ảnh mặc định) |
| `v19-chan-122cm.jpg.b64` | Ảnh chân 122cm |
| `v13-vong1.jpg.b64` | Ảnh vòng 1 chuẩn (v13) |
| `v19-vay-body-den.jpg.b64` | Ảnh váy body đen tự thiết kế |
| `v19-ho-eo.jpg.b64` | Ảnh eo/cơ bụng tốt nhất (crop top trắng hở eo) |

Ảnh khóa cũng đi kèm gói zip lúc cài bot, nên thư mục này chủ yếu để
dự phòng khi cài lại máy. Ảnh sản phẩm mới (`.b64`) cũng đẩy lên đây
theo hướng dẫn trong `lenh-runbook.md` mục 4.
